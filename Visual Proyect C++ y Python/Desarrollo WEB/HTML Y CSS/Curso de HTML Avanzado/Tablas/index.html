Costos Para El Desarrollo De Paginas Web

Contexto

Para el desarrollo de una pagina web se ocupa un capital para el desarrollo de la pagina el cual se proporcionara por medio del cliente que desee la creacion de su pagina web, en la siguiente tablaa se mostraran los precios que se tendran en cuenta para el desarrollo dependiendo de las funciones que desee el cliente y su precio final, estos precios estaran en paquetes describiendo el nivel del trabajo que se le dara en la pagina con costos extra dependiendo de si se quiere como prioridad o mas detalles, o funciones igualmente
